# 烬海纪元 · Ember Sea Era

> 单人 + AI 协作版 | 技术栈: Vite + TypeScript + Canvas 2D

## M0 技术验证已完成

- ✅ 32色调色板锁定（锈橙/铁灰/余烬金/骨白 + 冷青/幽紫荧光）
- ✅ 6区块地形生成（残骸带/龟裂荒原/戈壁矿脉/无声海/异兽巢穴/地底幽谷）
- ✅ 3地层可挖方块系统（浅层 0.3–1 / 中层 10–30 / 深层 40–70 硬度）
- ✅ 一格破坏系统 + 粒子飞溅 + 掉落物理
- ✅ 像素角色（最左侧剪影做比例锚点）+ 摄像机跟随
- ✅ Canvas 渲染器（视差背景 + 荧光 tile 发光）

## 快速开始

```bash
npm install
npm run dev       # http://localhost:5173
npm run build     # 产物 dist/
```

## 操作

| 按键 | 功能 |
|------|------|
| ← → / A D | 移动 |
| ↑ / W / 空格 | 跳跃 |
| 鼠标左键（6格内）| 破坏方块 |

## 项目结构

```
src/
├── main.ts           # 入口 & 主循环
├── style.css
├── vite-env.d.ts
└── core/
    ├── palette.ts    # 32色锁定调色板
    ├── blocks.ts     # 方块定义（硬度/层级）
    ├── terrain.ts    # 6区块 × 3地层 地形生成
    ├── camera.ts     # 摄像机
    ├── player.ts     # 玩家物理 + 碰撞
    ├── renderer.ts   # Canvas 渲染
    └── break.ts      # 一格破坏系统
```
